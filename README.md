# Ryan Sutawijaya — Portfolio & CV

Website pribadi berbahasa Indonesia untuk memperkenalkan Ryan Sutawijaya, pendekatannya terhadap UI/UX, dan proyek yang akan terus ditambahkan. Dibangun dengan Next.js App Router dan Tailwind CSS, lalu diekspor sebagai situs statis untuk GitHub Pages.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`. Untuk memeriksa hasil statis yang akan diterbitkan, jalankan `npm run build` dan lihat direktori `out/`.

## Isi

- Perkenalan dan cerita profesional
- Prinsip dan cara kerja desain
- Bidang kerja serta hal yang sedang dipelajari
- Tautan ke repositori portofolio

Perubahan pada branch `main` akan dibangun dan diterbitkan ke GitHub Pages oleh GitHub Actions. Konten proyek dan riwayat kerja bisa ditambahkan saat detailnya tersedia.
